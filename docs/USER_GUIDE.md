# PDF 编辑器 · 用户指南

本指南覆盖三大核心功能的使用说明、操作步骤与常见问题。

> 隐私提示：本应用所有文件处理均在本地完成，文件内容不会上传到任何服务器，可断网使用。

---

## 一、PDF 在线编辑

### 1. 打开文件

- 进入「编辑 PDF」，将 PDF 文件拖入虚线区域，或点击「选择 PDF 文件」。
- 桌面端可通过系统文件对话框选择；Web 端也可直接拖拽。

### 2. 工具栏工具

| 工具 | 用法 |
| --- | --- |
| 选择 | 点击元素选中；拖拽移动；选中后右上角 × 或 Delete 键删除 |
| 文本 | 点击原文弹出输入框，输入新内容后点击「替换」（导出时原文区域被遮盖并绘制新文本）；双击空白处可新增文本 |
| 高亮 | 拖拽框选区域；选中后可在属性面板改颜色/透明度 |
| 批注 | 拖拽放置便签图标，点击「i」后可输入批注文字 |
| 矩形 / 椭圆 / 箭头 / 线条 | 拖拽绘制；选中后在属性面板改颜色、线宽、填充 |
| 签名 | 点击后弹出签名面板：鼠标/触控手写，或导入图片，确认后添加到页面中央 |
| 图片 | 点击「插入图片」选择本地图片，自动插入当前页中央 |
| 抓手 | 平移视图（配合滚动） |

### 3. 页面管理

- 左侧缩略图栏：点击跳页；拖动缩略图可**重排页面**。
- 顶部工具栏：`+` 插入空白页（当前页之后）、`🗑` 删除当前页。
- 缩放：右下角 − / % / ＋ / 适应宽度。

### 4. 撤销 / 重做

- 工具栏按钮，或快捷键：`Ctrl+Z` 撤销、`Ctrl+Y` / `Ctrl+Shift+Z` 重做。
- 支持 ≥20 步操作历史。

### 5. 导出

- 点击右上角「导出」保存为 `原文件名-edited.pdf`。
- 导出特点：**未编辑的文本保持矢量、可搜索、可选中**；被替换文本区域以背景色遮盖并绘制新文本。
- 中文导出依赖捆绑的 Noto Sans SC 字体；若字体缺失，应用会明确提示（拉丁文本不受影响）。

## 二、PDF 转图片

### 1. 加载文件

进入「PDF 转图片」，拖拽或选择 PDF 文件。

### 2. 转换设置

| 设置 | 说明 |
| --- | --- |
| 输出格式 | PNG（无损，支持透明背景）/ JPG（有损，白色背景） |
| DPI 预设 | 屏幕 96 / 打印 150 / 高清 300，或自定义 72–600 |
| 额外倍率 | 在 DPI 基础上再放大（0.5–4） |
| 目标宽/高 px | 直接指定输出像素（0=自动按 DPI） |
| 页范围 | `all` 全部；`1-5,7` 指定页（1-based） |
| 背景 | 白色 / 透明（仅 PNG 有效） |

### 3. 转换与下载

- 点击「开始转换」，顶部进度条实时显示；可随时「取消」。
- 完成后网格预览：每张图片可单独下载；「打包 ZIP」一键下载全部（`原文件名-images.zip`）。
- 失败页面标红并显示原因，可点击「重试失败」单独重试，不影响成功页。

## 三、图片转 PDF

### 1. 添加图片

进入「图片转 PDF」，拖拽或点击选择多张图片。支持格式：**PNG / JPG / GIF / BMP / WebP**（GIF 取第一帧）。

- 缩略图下方可**旋转**（90° 步进）、**删除**；
- 拖动缩略图可调整顺序（生成顺序与列表顺序一致）；
- 损坏/不支持的图片会标红提示，**不影响其他图片**。

### 2. 版式设置

| 设置 | 说明 |
| --- | --- |
| 页面尺寸 | A4 / Letter / 自定义（宽高，单位 pt） |
| 页边距 | 0–200 pt |
| 图片适配 | 包含（完整显示居中留白）/ 铺满（裁切溢出）/ 拉伸（填满页面） |
| 缩放比例 | 0.1–4，额外放大/缩小 |

### 3. 生成与下载

- 点击「生成 PDF」，进度条实时显示，可取消。
- 完成后可「预览」或「下载」（`images.pdf`）。

## 四、常见问题（FAQ）

**Q：文件会上传到服务器吗？**
A：不会。所有解析、渲染、编辑、转换均在本机完成，无任何网络请求。

**Q：编辑后的 PDF 原文还能选中/搜索吗？**
A：可以。导出采用复制原页内容流（copyPages）的方式，未编辑文本保持矢量可搜索；被替换文本区域以背景色遮盖并绘制新文本。

**Q：导出中文时提示「需要字体资源」怎么办？**
A：中文导出需要捆绑的 Noto Sans SC 字体（OFL）。请联网后在项目目录执行 `npm run fetch:font` 后重启应用；或使用拉丁字符（英文/数字），无需字体资源。

**Q：PDF 转图片输出尺寸不精确？**
A：输出按 DPI/72 × 额外倍率计算，存在取整误差，验收允许 ±2%。

**Q：Web 端能处理多大的文件？**
A：>100MB 会提示性能风险但仍允许尝试；桌面端无硬限制。

**Q：高亮导出颜色和预览有差异？**
A：pdf-lib 混合模式有限，高亮导出以透明度矩形近似，存在轻微色差属正常。
